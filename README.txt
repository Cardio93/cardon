CARDÓN · Visor DICOM para imágenes cardiovasculares
Software libre (GNU GPL v3) · Solo para uso educativo

Ecocardiograma, angiografía coronaria, TC y RM cardíacas en un solo programa, con pacientes,
mediciones y reporte. Funciona sin internet y las imágenes no salen del computador.

  Página y descarga:      index.html (GitHub Pages)
  Usar en el navegador:   app/
  Instalador:             descargas/Cardon-instalador.zip  (Windows y Linux)
  Código fuente:          codigo/  (ver codigo/COMO-COMPILAR.txt)
  Licencia:               LICENSE
